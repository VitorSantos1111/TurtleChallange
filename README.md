# Turtle challange  
A turtle must walk through a mine field.  

## Usage  
The executable accepts 3 possible argument sets:
1. **To run the game**  
TurtleChallange \<settings file> \<moves file>  
2. **Create an exaple settings file**  
TurtleChallange -s \<settings file>  
If no settings file is given, it will create a **settings.json** file in the executable directory.  
3. **Create an exaple moves file**  
TurtleChallange -m \<moves file>  
If no moves file is given, it will create a **actions.csv** file in the executable directory.
